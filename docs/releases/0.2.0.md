# Junto 0.2.0

Junto is a self-hosted application for team text chat, voice and video calls, screen sharing, and call recording with transcripts. Version 0.2.0 follows 0.1.0.

## What is new

### Client

- The text of the composer is formatted while you write it.
- Favourites are the only personal group of the channel list. Named personal sections of 0.1.0 are not kept; their channels return to the categories of the server.
- The group of direct messages collapses like a category of the server.
- A workspace can have a logo, which the workspace list shows.
- The menu of a server offers "Join workspaces with an invite", and a pasted invite link opens with its code.
- "Start Junto at login" works for every profile, each with its own entry.
- On Linux, the 12- or 24-hour clock also follows the setting of KDE Plasma, Xfce, Cinnamon and MATE.
- Large photos are decoded at the size at which they are drawn, which takes less memory and time.
- The release notes are shown once after an update, and from the settings.
- A saved server without a common API version is shown as incompatible.
- The place where an export was saved is still shown after a restart.
- An emoji in a message has a tooltip with its name.
- When another program holds the data of Junto, the client says so instead of waiting.
- The lists of the administration screens name every item for assistive technology.

### Calls and media

- The share dialog has the tabs Screen, Window and Application. An application share shows every window of one application, also windows that it opens later. On Linux there is no Application tab, as the desktop portal offers no such source.
- On macOS, a shared window that changes size is followed by the share.
- The quality of a share follows the size of its pictures.
- Turning the sound of a call off also mutes the microphone. Turning the sound on returns the microphone to how it was. This is a setting, on by default.
- The noise suppression of the microphone lowers typing and clicks a little, besides steady noise such as a fan.
- On Windows, cameras that only DirectShow lists can be used.
- A call with hundreds of people draws much faster: only the tiles and the rows in view are built.
- Each device list of the voice settings has the icon of its kind.

### Server and administration

- The positions of categories and channels that a person receives are their places among those that the person sees, so a gap no longer tells how many are hidden. Clients of 0.1.0 keep the meaning of positions that they know.
- The setup tool keeps the order of a structure file exactly.
- After the restore of a backup made during a recording, the recorder no longer records an empty call.

### Deployment

- In the two-host form, each end of the private link restarts when no packet passes for a bound, and can send a notice when the link goes down and when it is up again (`JUNTO_LINK_NOTICE_URL`).
- The link bounds the connections of each of its forwarders. `JUNTO_LINK_PIDS` raises the number of connections of clients for a server with many devices.

## Contents

- Text chat: text channels, direct messages, replies, mentions, reactions, edit and delete, formatting with code blocks, attachments with image previews, threads, pins, unread signs, notification levels with mute and do not disturb, search over messages and transcripts, permanent-message channels, archive and export.
- Voice and video calls: voice channels with their own text chat, video, meeting mode, a lock and a user limit for a voice channel, invite and move between voice channels, and direct-message calls.
- Screen sharing of a screen, a window or an application, with sound.
- Call recording, and transcripts with speaker separation and a workspace glossary.
- Administration: server roles and workspace roles with channel permissions, several workspaces per server with their logos, a device list per account, an audit log, administration screens, administrator access tokens, the setup command-line tool and generated API documentation.
- The desktop client for macOS, Windows and Linux, with the server book, the update notice, the release notes and interface scaling.
- The server, installed with Docker Compose on one host or on two hosts.

## Supported systems

- macOS 26 on Apple Silicon. Older versions of macOS are not blocked and are not tested.
- Windows 11 on x86-64.
- Linux on x86-64 with PipeWire, under X11 or Wayland, with glibc 2.35 or newer.

## Packages

- macOS: `Junto-0.2.0-macos-aarch64.dmg`, a disk image with `Junto.app` and a link to the Applications folder, and `Junto-0.2.0-macos-aarch64.zip`, which holds `Junto.app`.
- Windows: `Junto-0.2.0-windows-x86_64-setup.exe`, a setup program that installs Junto for the account without administrator rights, with an entry in the Start menu and in the list of installed programs, and `Junto-0.2.0-windows-x86_64.zip`, which holds the folder `Junto`. `Junto-0.2.0-windows-x86_64.pdb` holds the symbols of `junto.exe`; it resolves the frames of an error report of the Windows client and is not needed to run Junto.
- Linux: `Junto-0.2.0-x86_64.AppImage`, `junto-0.2.0-linux-x86_64.tar.gz` with the directory `junto`, and `junto_0.2.0_amd64.deb`.

`SHA256SUMS` holds the SHA-256 of each file.

## First start

Junto has no paid code signature.

- macOS blocks the first open of a downloaded copy, and the dialog has no button that opens Junto. Open System Settings, Privacy & Security, choose "Open Anyway" for Junto, then confirm.
- On Windows, Microsoft Defender SmartScreen shows "Windows protected your PC" at the first start. Choose "More info", then "Run anyway". Smart App Control must be off; with it on, Windows does not run Junto.
- On Linux, the AppImage needs `chmod +x` and `fusermount` of FUSE 2 or 3; without FUSE, start it with `--appimage-extract-and-run`. Install the `.deb` with `sudo apt install ./junto_0.2.0_amd64.deb`.

## From 0.1.0

Clients of 0.1.0 update themselves to 0.2.0: Update on the notice, or Install update in Settings, Version. The `.deb` is installed by hand with `sudo apt install ./junto_0.2.0_amd64.deb`. The server is upgraded as the section "Upgrade" of `docs/install.md` describes, with a backup first; the section also describes the way back.

## Updates

Junto installs updates from inside the application: Update on its notice, or Install update in Settings, Version. It reads them from the GitHub releases of `https://github.com/luifon/junto` and verifies them with the keys of the project. The `.deb` is the exception: Junto cannot update a system package, so a newer version is installed with `sudo apt install` and the `.deb` of that version.

## Server

The server is installed, backed up and upgraded as `docs/install.md` of the source repository describes.
