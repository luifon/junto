# Junto 0.1.0

Junto is a self-hosted application for team text chat, voice and video calls, screen sharing, and call recording with transcripts. Version 0.1.0 is the first release.

## Contents

- Text chat: text channels, direct messages, replies, mentions, reactions, edit and delete, formatting with code blocks, attachments with image previews, threads, pins, unread signs, notification levels with mute and do not disturb, search over messages and transcripts, permanent-message channels, archive and export.
- Voice and video calls: voice channels with their own text chat, video, meeting mode, a lock and a user limit for a voice channel, invite and move between voice channels, and direct-message calls.
- Screen sharing with sound.
- Call recording, and transcripts with speaker separation and a workspace glossary.
- Administration: server roles and workspace roles with channel permissions, several workspaces per server, a device list per account, an audit log, administration screens, administrator access tokens, the setup command-line tool and generated API documentation.
- The desktop client for macOS, Windows and Linux, with the server book, the update notice and interface scaling.
- The server, installed with Docker Compose on one host or on two hosts.

## Supported systems

- macOS 26 on Apple Silicon. Older versions of macOS are not blocked and are not tested.
- Windows 11 on x86-64.
- Linux on x86-64 with PipeWire, under X11 or Wayland, with glibc 2.35 or newer.

## Packages

- macOS: `Junto-0.1.0-macos-aarch64.dmg`, a disk image with `Junto.app` and a link to the Applications folder, and `Junto-0.1.0-macos-aarch64.zip`, which holds `Junto.app`.
- Windows: `Junto-0.1.0-windows-x86_64-setup.exe`, a setup program that installs Junto for the account without administrator rights, with an entry in the Start menu and in the list of installed programs, and `Junto-0.1.0-windows-x86_64.zip`, which holds the folder `Junto`. `Junto-0.1.0-windows-x86_64.pdb` holds the symbols of `junto.exe`; it resolves the frames of an error report of the Windows client and is not needed to run Junto.
- Linux: `Junto-0.1.0-x86_64.AppImage`, `junto-0.1.0-linux-x86_64.tar.gz` with the directory `junto`, and `junto_0.1.0_amd64.deb`.

`SHA256SUMS` holds the SHA-256 of each file.

## First start

Junto has no paid code signature.

- macOS blocks the first open of a downloaded copy, and the dialog has no button that opens Junto. Open System Settings, Privacy & Security, choose "Open Anyway" for Junto, then confirm.
- On Windows, Microsoft Defender SmartScreen shows "Windows protected your PC" at the first start. Choose "More info", then "Run anyway". Smart App Control must be off; with it on, Windows does not run Junto.
- On Linux, the AppImage needs `chmod +x` and `fusermount` of FUSE 2 or 3; without FUSE, start it with `--appimage-extract-and-run`. Install the `.deb` with `sudo apt install ./junto_0.1.0_amd64.deb`.

## From the test versions

Clients of the test versions 0.1.0-test.1 and 0.1.0-test.2 do not update themselves to 0.1.0. Install 0.1.0 by hand once, with a package of this release, in place of the test version. On macOS, Junto asks again once for the permissions that the test versions had, such as the microphone, the camera and the screen: 0.1.0 is the first release that is signed with the permanent code-signing identity.

## Updates

After 0.1.0, Junto installs updates from inside the application: Update on its notice, or Install update in Settings, Version. The `.deb` is the exception: Junto cannot update a system package, so a newer version is installed with `sudo apt install` and the `.deb` of that version.

## Server

The server is installed, backed up and upgraded as `docs/install.md` of the source repository describes.
