# Junto 0.2.1

Junto is a self-hosted application for team text chat, voice and video calls, screen sharing, and call recording with transcripts. Version 0.2.1 follows 0.2.0. It has no change of the database.

## What is new

### Client

- The devices of calls are chosen in one place: Settings, "Voice and video". The choice works also during a call and changes the devices of the call at once. In a call, the input meter shows the level of the call's microphone, and the camera preview shows the picture that the call sends. The device check before a join has the same lists.
- "Voice and video" also holds "Your screen share" (resolution and frame rate) and "Your view" (hide people without video, hide your camera tile).
- The settings have a section "Call" with the settings of the room of the call you are in: meeting mode, the lock, the user limit and "Hide who is in the call". These settings apply to everyone in the call. Outside a call the section states that it has no settings to show.
- The panel of a call has Chat and Members. The settings button of the call opens Settings at "Voice and video"; in the call window it opens them in the main window. The volume of a watched share is on the line of the share.
- A window of Junto and the Junto application can be shared, with their picture only, never with the sound of Junto. While you share Junto, your stage shows a statement in place of the picture of your share.

### Calls and media

- A camera can be used at any size that it offers, up to 4K; the picture is sent scaled to fit 1280 × 720. Virtual cameras such as OBS Virtual Camera and NVIDIA Broadcast offer only the size that their application sets, which Junto did not accept before.
- On Windows, a camera that DirectShow lists can also send MJPEG, UYVY, RGB24 or RGB32 pictures.
- When a camera does not start, the log names the camera, the formats that it offers and the step that failed.

### Corrections

- On Windows, a virtual camera such as OBS Virtual Camera or NVIDIA Broadcast no longer fails with "The camera cannot be used on this system."
- The device lists of the settings open during a call, after a call ended and after a change of the account of the server. A press on another list while one list is open opens that list.
- A slow camera list no longer delays the lists of the microphones and the speakers.
- On Windows, the first press on the taskbar button after a minimize restores the window. Before, a second press was needed.
- A move of a person to the AFK channel no longer tells the members of the server that a call started there. This needs the server and the client of 0.2.1; a client of 0.2.0 still shows it.

## Supported systems

- macOS 26 on Apple Silicon. Older versions of macOS are not blocked and are not tested.
- Windows 11 on x86-64.
- Linux on x86-64 with PipeWire, under X11 or Wayland, with glibc 2.35 or newer.

## Packages

- macOS: `Junto-0.2.1-macos-aarch64.dmg`, a disk image with `Junto.app` and a link to the Applications folder, and `Junto-0.2.1-macos-aarch64.zip`, which holds `Junto.app`.
- Windows: `Junto-0.2.1-windows-x86_64-setup.exe`, a setup program that installs Junto for the account without administrator rights, with an entry in the Start menu and in the list of installed programs, and `Junto-0.2.1-windows-x86_64.zip`, which holds the folder `Junto`. `Junto-0.2.1-windows-x86_64.pdb` holds the symbols of `junto.exe`; it resolves the frames of an error report of the Windows client and is not needed to run Junto.
- Linux: `Junto-0.2.1-x86_64.AppImage`, `junto-0.2.1-linux-x86_64.tar.gz` with the directory `junto`, and `junto_0.2.1_amd64.deb`.

`SHA256SUMS` holds the SHA-256 of each file.

## First start

Junto has no paid code signature.

- macOS blocks the first open of a downloaded copy, and the dialog has no button that opens Junto. Open System Settings, Privacy & Security, choose "Open Anyway" for Junto, then confirm.
- On Windows, Microsoft Defender SmartScreen shows "Windows protected your PC" at the first start. Choose "More info", then "Run anyway". Smart App Control must be off; with it on, Windows does not run Junto.
- On Linux, the AppImage needs `chmod +x` and `fusermount` of FUSE 2 or 3; without FUSE, start it with `--appimage-extract-and-run`. Install the `.deb` with `sudo apt install ./junto_0.2.1_amd64.deb`.

## From 0.2.0

Clients of 0.2.0 update themselves to 0.2.1: Update on the notice, or Install update in Settings, Version. The `.deb` is installed by hand with `sudo apt install ./junto_0.2.1_amd64.deb`. The server is upgraded as the section "Upgrade" of `docs/install.md` describes, with a backup first; 0.2.1 has no database migration, so the server of 0.2.0 can be started again on the same database.

## Updates

Junto installs updates from inside the application: Update on its notice, or Install update in Settings, Version. It reads them from the GitHub releases of `https://github.com/luifon/junto` and verifies them with the keys of the project. The `.deb` is the exception: Junto cannot update a system package, so a newer version is installed with `sudo apt install` and the `.deb` of that version.

## Server

The server is installed, backed up and upgraded as `docs/install.md` of the source repository describes.
