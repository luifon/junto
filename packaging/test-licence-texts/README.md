# Licence texts of the tests

`test_licences.py` reads these texts to check that `LICENCE_PHRASES` in `licences.py` identifies the full text of a licence that has no standard text in `licence-texts/`. The packages never use them. Each file is the text of the SPDX License List, release 3.27.0 (`https://github.com/spdx/license-list-data/tree/v3.27.0/text`), unchanged, named by its SPDX identifier.
